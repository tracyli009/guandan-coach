# AI 掼蛋教练 Knowledge Base

这是为 AI Project / GitHub 检索优化的 Markdown 版本。

## 推荐加载顺序
1. `00_AI教练使用说明.md`
2. `01_核心牌理.md`
3. `04_炸弹决策.md`
4. `05_搭档与牌型判断.md`
5. `06_残局与心理.md`
6. 其余专项训练与案例文件

## 文件结构
- 核心知识：01–06
- 训练题：07–08
- 实战案例：09
- 训练与复盘：10
- 来源与编写说明：11

## 设计原则
- 标题层级清楚，方便语义检索。
- 将“规则、判断、训练、案例”分开，降低检索混淆。
- 实战回答优先遵循 `00_AI教练使用说明.md`。
- 案例是教学情境，不应被当作唯一固定打法；真实牌局应结合已出牌与规则重新判断。
